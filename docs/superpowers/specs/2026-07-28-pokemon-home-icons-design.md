## 配置接口

在 `source/_data/notebook.yml` 的每个 `destinations` 条目中增加 `icon` 字段：

```yaml
destinations:
  - id: projects
    label: 作品
    subtitle: Projects
    url: /projects/
    accent: blue
    icon: /img/pokemon/pikachu.png
```

更换图标的唯一操作是：

1. 将新图片放入 `source/img/pokemon/`。
2. 修改对应入口的 `icon` 路径。

模板不维护宝可梦名称或文件映射。若 `icon` 缺失，模板回退到现有 SVG 图标组件，保证配置错误时入口仍可识别和访问。

## 布局

桌面端使用三列网格：

- 第一排：作品、文章、关于。
- 第二排：GitHub、联系。
- 第二排两个卡片整体居中。
- 入口区域最大宽度约 `820px`。
- 列间距控制在 `32–40px`，行间距约 `28px`，避免卡片集中在页面中央。
- 卡片保留现有彩色背景、圆角、明暗主题和悬停反馈。

手机端：

- 使用两列排列。
- 前四个入口形成 `2 + 2`。
- 最后一个“联系”卡片位于第三排并居中。
- 极窄屏幕继续使用现有单列降级规则。

## 图标呈现

- 模板使用 `<img>` 渲染配置图片。
- 图片显示区域统一，使用 `object-fit: contain`。
- 图片不拉伸、不裁切，保留透明背景。
- 宝可梦图标比当前线性 SVG 更具视觉重量，因此尺寸应控制在卡片可读范围内，不能挤压中英文标题。
- `alt` 使用入口中文名称；入口链接本身继续提供完整可访问名称。
