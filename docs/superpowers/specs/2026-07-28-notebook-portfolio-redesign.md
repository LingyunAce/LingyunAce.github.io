# 凌云个人网站“笔记本索引”改版设计规格

**日期：** 2026-07-28  
**状态：** 设计已确认，等待书面规格复核  
**目标站：** https://lingyunace.github.io/  
**参考站：** https://tangweijuan.com/  
**仓库：** `LingyunAce/LingyunAce.github.io`

## 1. 目标

在保留 Hexo、Butterfly、现有文章和部署方式的前提下，把凌云个人网站
改造成具有独立品牌的“笔记本索引”站点。

改版借鉴参考站的空间关系和交互语言：方格纸、线圈、便签、轻微旋转、
手绘式标记、低密度首页和标签式内页导航。不得复制参考站的商标、插画、
图标、文案或个人信息。

## 2. 已确认的设计决策

- 采用方案 A：索引型首页 + 全站统一。
- 同时提供浅色和暗色主题。
- 首页作为六个主要目的地的导航入口，不再承载完整作品、文章和关于内容。
- 作品、文章归档、关于及文章详情页使用统一标签导航、设计令牌和页脚。
- 保留 Hexo + Butterfly，不迁移框架。
- 保留现有项目数据、文章内容、GitHub 链接和邮箱。
- “凌云”字标和六枚入口图标必须原创。

## 3. 非目标

- 不复制参考站的像素级布局。
- 不下载或复用参考站的 logo、插画、图标和内容图片。
- 不新增 CMS、数据库、评论后端、账号系统或服务端运行时。
- 不重写 Hexo 的文章、标签、分类和归档生成逻辑。
- 不在本次改版中补造真实项目截图；没有图片时使用原创的排版型封面。
- 不改变 GitHub Pages 的现有发布目标。

## 4. 信息架构

### 4.1 首页 `/`

首页为一个居中的大型笔记本画布，包含：

1. 原创“凌云 · LingyunAce”字标。
2. 角色说明：`Independent Developer · Writer`。
3. 六张入口卡片：
   - 作品 → `/projects/`
   - 文章 → `/archives/`
   - 随记 → `/tags/随笔/`
   - 关于 → `/about/`
   - GitHub → `https://github.com/LingyunAce`
   - 联系 → `mailto:543491395@qq.com`
4. 主题切换按钮。
5. 精简页脚。

入口卡片使用原创线性图标、黑色胶囊标签和固定的小角度旋转。旋转仅为
视觉效果，DOM 顺序保持从左到右、从上到下。

### 4.2 作品 `/projects/`

- 共享字标和标签式导航。
- 页面标题与原创作品图标。
- 项目筛选按钮。
- 项目数据继续读取 `source/_data/projects.yml`。
- 卡片显示封面、名称、描述、年份、技术标签和外部链接。
- 没有真实封面时使用原创排版封面，不显示破图。

### 4.3 文章归档 `/archives/`

- 共享字标和标签式导航。
- 搜索入口与标签/分类入口。
- 以日期、标题和摘要组成高密度时间列表。
- 保留 Hexo 的分页、标签、分类和归档链接。

### 4.4 关于 `/about/`

在点阵纸画布上分布四到五张纸质便签：

- 自我介绍
- 正在做的方向
- 常用技术与工具
- 兴趣
- 联系方式

宽屏使用轻微旋转和错落布局；窄屏按上述顺序垂直排列。

### 4.5 文章详情

- 保留 Butterfly 的 Markdown、代码块、目录和上下篇功能。
- 用共享标签导航和页脚替换外层视觉。
- 阅读正文不使用旋转或方格背景，避免降低可读性。
- 正文最大宽度约 760px。

## 5. 视觉系统

设计令牌以根级 CSS 自定义属性维护。

### 5.1 浅色主题

- 外层画布：`#ECEBEB`
- 纸张：`#FCF9FB`
- 主文字：`#171717`
- 次文字：`#686166`
- 网格线：`rgba(212, 203, 211, 0.38)`
- 边框：`#E8E1E5`
- 主标记色：`#EF4F98`
- 辅助色：蓝 `#69B8FF`、黄 `#FFD34D`、紫 `#9B8CFF`、
  绿 `#6BD4A2`、橙 `#FF9E63`

### 5.2 暗色主题

- 外层画布：`#151515`
- 纸张：`#242225`
- 主文字：`#F4F1F3`
- 次文字：`#B8B0B5`
- 网格线：`rgba(255, 255, 255, 0.055)`
- 边框：`#454046`
- 主标记色沿用 `#EF4F98`
- 辅助色保持色相，适当降低饱和度或提高亮度以满足对比度

### 5.3 字体

- UI 与正文：`Inter`, `Noto Sans SC`, `system-ui`, `sans-serif`
- 字标：原创 SVG，不依赖第三方手写字体
- 正文字号不小于 16px
- 列表日期和辅助标签不小于 12px

### 5.4 形状与动效

- 笔记本外框圆角：28-36px
- 纸卡默认近似直角，仅允许 0-4px 小圆角
- 卡片旋转：`-2deg` 到 `2deg`
- 动效：160-240ms
- 悬停：卡片回正、上移 4px、阴影加深
- `prefers-reduced-motion: reduce` 时取消位移和旋转动画

## 6. 响应式

### 桌面端

- 内容最大宽度 1200-1320px。
- 首页入口卡片使用三列或 4+2 布局。
- 显示线圈、错落便签和轻微旋转。

### 平板端

- 首页入口卡片两列。
- 标签导航允许水平滚动。
- 作品网格两列。

### 手机端

- 目标验证宽度为 390px。
- 隐藏线圈等不必要装饰。
- 首页入口卡片两列；极窄宽度允许单列。
- 作品卡片单列。
- 关于便签按语义顺序单列。
- 所有交互目标最小 44×44px。

## 7. 主题行为

- 首次访问优先使用 `prefers-color-scheme`。
- 用户手动切换后写入 `localStorage`。
- 后续访问优先使用已保存选择。
- 切换控件提供可读标签和 `aria-pressed` 状态。
- 禁用 JavaScript 时默认显示可读的浅色主题；核心导航和内容不受影响。

## 8. 代码结构

计划引入以下边界：

- `themes/butterfly/layout/includes/notebook/`
  - 共享字标、标签导航、主题切换与页脚
- `themes/butterfly/layout/notebook-home.pug`
  - 首页结构
- `themes/butterfly/layout/notebook-projects.pug`
  - 作品页结构
- `themes/butterfly/layout/notebook-about.pug`
  - 关于页结构
- `source/css/notebook.css`
  - 设计令牌、共享组件、主题和响应式样式
- `source/js/notebook.js`
  - 主题切换、移动导航和项目筛选
- `source/img/notebook/`
  - 原创字标和 SVG 图标

文章归档和文章详情尽量保留 Butterfly 现有 Pug 结构，通过小范围 include
和样式层统一外观，不复制其渲染逻辑。

## 9. 数据流

- Hexo 读取 Markdown 文章并生成文章详情、标签、分类与归档。
- `source/_data/projects.yml` 是项目卡片的唯一数据来源。
- Pug 在构建期渲染导航、项目和静态内容。
- 浏览器端 JavaScript 不请求接口，只处理视图状态。
- 筛选按钮通过项目标签控制已渲染卡片的可见性。

## 10. 降级与异常处理

- 项目封面缺失：显示项目名构成的排版封面。
- 项目链接缺失：卡片不渲染为外部链接，并显示“暂未公开”。
- 项目列表为空：显示明确的空状态。
- 主题存储不可用：忽略存储错误，继续使用系统主题。
- JavaScript 加载失败：页面保持完整导航和内容，只失去筛选与手动主题切换。
- SVG 加载失败：保留文字标签，导航仍可识别。

## 11. 可访问性

- 使用语义化的 `header`、`nav`、`main`、`section` 和 `footer`。
- 提供“跳到主内容”链接。
- 当前导航项使用 `aria-current="page"`。
- 键盘焦点使用清晰的 2px 轮廓。
- 装饰线圈、胶带、网格和阴影不进入辅助技术的阅读顺序。
- 浅色和暗色主题均满足正文 WCAG AA 对比度。
- 项目筛选切换后向辅助技术报告结果数量。

## 12. 验证

### 自动验证

- `npm ci`
- `npm run clean`
- `npm run build`
- 检查生成的 `/`、`/projects/`、`/about/`、`/archives/` 和至少一个文章详情页。
- 检查构建日志中没有缺失模板、资源或无效 YAML 错误。

### 浏览器验证

- 1440px 桌面截图。
- 390px 手机截图。
- 浅色和暗色各验证一次。
- 验证系统主题、手动切换和刷新后持久化。
- 验证项目筛选、标签导航、外部链接和邮件链接。
- 只用键盘完成首页到核心内页的导航。
- 验证 `prefers-reduced-motion`。

## 13. 成功标准

1. 首页在首次打开时明确呈现凌云身份和六个入口。
2. 首页、作品、归档、关于和文章详情具有一致的品牌语言。
3. 浅色和暗色均完整可用，并能记忆用户选择。
4. 现有文章、项目数据和 GitHub Pages 发布流程不丢失。
5. 桌面和手机没有横向溢出、遮挡或不可点击元素。
6. `npm run build` 成功完成。
7. 不包含参考站受保护的视觉资产或文案。
